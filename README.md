# EduGenie

EduGenie is a Google Gemini powered AI learning assistant built with:

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Pydantic

## Features

EduGenie provides five major learning features:

1. Ask Questions
2. Explain Concepts
3. Generate Quizzes
4. Summarize Study Material
5. Generate Personalized Learning Paths
